# Spanish Daily Lesson 27: Muy vs Mucho Without Guessing

## 1) cognitive_shift

**English trap**  
Using one word for both "very" and "a lot" and translating directly.

**Spanish logic**  
Spanish separates these meanings by function:
- `muy` intensifies adjectives/adverbs.
- `mucho` modifies verbs (a lot), stands alone in short answers, and agrees with nouns as adjective (`mucha/muchos/muchas`).

**target pattern / formula**  
- `muy + adjective/adverb` -> `muy dificil`, `muy rapido`  
- `verb + mucho` -> `trabajo mucho`  
- short answer: `Si, mucho.`  
- `mucho + noun` with agreement -> `mucha agua`, `muchos amigos`  
- never use standalone `muy` in this core pattern set

**5 natural examples**  
1. El reporte esta muy claro.  
2. Trabajo mucho los lunes.  
3. Si, mucho.  
4. Hay mucha comida en la oficina.  
5. Tenemos muchos clientes nuevos.

## 3) pattern_mutation

Transform each base sentence as instructed.

1. Base: El examen es muy dificil. -> change adjective to `facil`.  
2. Base: Ella estudia mucho. -> change subject to `nosotros`.  
3. Base: El cafe esta muy caliente. -> change adjective to `frio`.  
4. Base: Trabajo mucho. -> make it negative.  
5. Base: Hay mucha comida. -> change noun to masculine plural (`libros`).  
6. Base: Hay muchos clientes. -> change noun to feminine singular (`gente`).  
7. Base: El informe es muy claro. -> change subject noun to plural (`los informes`).  
8. Base: Si, mucho. -> turn into answer to `Estan cansados?`.  
9. Base: Tenemos muchos problemas. -> change to singular feminine noun (`presion`).  
10. Base: Hablan mucho en clase. -> change subject to `yo`.  
11. Base: La casa esta muy limpia. -> change adjective to `ordenada`.  
12. Base: Ella tiene mucha tarea. -> change to plural masculine noun (`proyectos`).  
13. Base: Necesito muchos amigos aqui. -> change intensity target to `mucha ayuda`.  
14. Base: Corres muy rapido. -> change to `lento`.  
15. Base: Juan se queja mucho. -> change subject to plural `ellos`.

## 7) common_errors

1. **Mistake:** `mucho dificil`  
   **Why it happens:** Mixing the intensifier function with quantity form.  
   **Correct Spanish:** `muy dificil`

2. **Mistake:** `muy` after verbs for quantity  
   **Why it happens:** Translating "very" for "a lot".  
   **Correct Spanish:** `trabajo mucho`

3. **Mistake:** `Si, muy.` as standalone answer  
   **Why it happens:** Forgetting standalone rule.  
   **Correct Spanish:** `Si, mucho.`

4. **Mistake:** `mucho agua`  
   **Why it happens:** Not matching adjective to noun gender/number.  
   **Correct Spanish:** `mucha agua`

5. **Mistake:** `mucho sillas`  
   **Why it happens:** Missing plural feminine agreement.  
   **Correct Spanish:** `muchas sillas`

6. **Mistake:** `muchos tarea`  
   **Why it happens:** Forcing masculine plural by default.  
   **Correct Spanish:** `mucha tarea`

7. **Mistake:** `muy trabajo`  
   **Why it happens:** Using `muy` before noun.  
   **Correct Spanish:** `mucho trabajo`

8. **Mistake:** `estan muchos cansados`  
   **Why it happens:** Treating adjective intensifier like agreeing adjective.  
   **Correct Spanish:** `estan muy cansados`

9. **Mistake:** `hablan muchas` for verb quantity  
   **Why it happens:** Over-applying agreement where adverb needed.  
   **Correct Spanish:** `hablan mucho`

10. **Mistake:** Switching randomly between `muy` and `mucho`  
    **Why it happens:** Not deciding by what word is modified.  
    **Correct Spanish:** adjective/adverb -> `muy`; verb or standalone -> `mucho`; noun -> agreeing `mucho/a/os/as`.
