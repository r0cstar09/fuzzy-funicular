# Spanish Daily Lesson 14 (Writing-First)

## 1) cognitive_shift

- **English trap:** Translating every “know” as one verb.
- **Spanish logic:** Spanish splits “know” into patterns: `saber` (facts/info/skills), `conocer` (people/places/things you’re familiar with), and `saber cómo` (method/process).
- **target pattern/formula:**
  - `saber + dato / si / dónde / quién`
  - `saber + infinitivo` (know how, general skill)
  - `saber cómo + infinitivo` (know the method/steps)
  - `conocer + (a + persona)` / `conocer + lugar/cosa`

### 5 natural examples
1. ¿Sabes dónde está el hotel?
2. Sé cocinar, pero no sé cómo hacer paella.
3. ¿Conoces a María?
4. No conozco esa ciudad.
5. ¿Sabes si Juan quiere venir?

## 3) pattern_mutation

Transform each base sentence as instructed.

1. Base: `¿Conoces a Juan?` -> change to first-person statement.
2. Base: `Sé cocinar.` -> make it negative.
3. Base: `No sé cómo empezar.` -> make it affirmative.
4. Base: `¿Sabes dónde está el hotel?` -> change `hotel` to `banco`.
5. Base: `Conozco la ciudad.` -> make it negative.
6. Base: `¿Sabes nadar?` -> change to `nosotros`.
7. Base: `¿Conoces a mi hermana?` -> change to plural object `mis hermanos`.
8. Base: `Sé hablar español.` -> turn into question (`tú`).
9. Base: `No conocemos ese restaurante.` -> make it affirmative.
10. Base: `¿Sabes si Juan viene?` -> change Juan to María.
11. Base: `Sé cómo explicar esto.` -> make it negative.
12. Base: `¿Quieres conocer a mi amigo?` -> change to `tengo que`.
13. Base: `No sé la respuesta.` -> change to question form.
14. Base: `Conozco la canción.` -> change meaning to “know the lyrics.”
15. Base: `Sabemos cómo llegar a la casa de Ana.` -> change to singular `yo`.

## 7) common_errors

1. **Using `saber` with people**  
   Why: English uses one “know.”  
   Correct: `Conozco a Juan.`
2. **Using `conocer` for facts**  
   Why: Learner maps “know” blindly.  
   Correct: `Sé la respuesta.`
3. **Forgetting personal `a` with people after `conocer`**  
   Why: English has no equivalent marker.  
   Correct: `¿Conoces a María?`
4. **Using `saber cómo` when only skill is intended**  
   Why: Over-explicit structure every time.  
   Better general skill: `Sé nadar.`
5. **Using plain `saber + infinitive` when method is focus**  
   Why: Method vs ability distinction unclear.  
   Better method focus: `No sé cómo empezar.`
6. **Using `conocer` with question clauses (`si/dónde`)**  
   Why: Literal transfer from English clause syntax.  
   Correct: `¿Sabes si... ?`, `¿Sabes dónde... ?`
7. **Wrong person conjugation (`yo sabe`)**  
   Why: Irregular first person `sé` not memorized.  
   Correct: `Yo sé`, `yo conozco`.
8. **Dropping accent in `sé`**  
   Why: Fast typing.  
   Correct: `Sé cocinar.`
9. **Mixing `conocer` with infinitive directly**  
   Why: Following modal patterns by habit.  
   Correct: `Sé cocinar`, not `conozco cocinar`.
10. **Using `saber` for familiarity with a city/movie**  
    Why: Facts vs familiarity not separated.  
    Correct: `Conozco la ciudad`, `Conozco la película`.
