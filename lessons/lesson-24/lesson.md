# Spanish Daily Lesson 24: TENER Chunks That Replace "To Be"

## 1) cognitive_shift

**English trap**  
Saying `estoy` for hunger, thirst, age, and urgency because English uses "I am..."

**Spanish logic**  
Spanish uses **tener + noun** for many personal states (`hambre`, `sed`, `sueno`, `prisa`, `anos`, `ganas de`).  
Use **hacer** for weather/ambient temperature, and **estar + adjective** for object temperature.

**target pattern / formula**  
- Personal state: `tener + noun` (`Tengo hambre`, `Tengo frio`)  
- Age: `tener + number + anos`  
- Desire: `tener ganas de + infinitive`  
- Weather: `hace calor/frio`  
- Object temp: `esta caliente/frio`; intensity: `mucho` with `tener/hacer`, `muy` with adjectives

**5 natural examples**  
1. Tengo mucha hambre despues del trabajo.  
2. Ella tiene 32 anos.  
3. Tenemos ganas de salir esta noche.  
4. Hace mucho calor hoy.  
5. El cafe esta muy caliente.

## 3) pattern_mutation

Transform each base sentence as instructed.

1. Base: Tengo hambre. -> intensify with `mucha`.  
2. Base: Tenemos sed. -> change subject to `yo`.  
3. Base: Tengo frio. -> change to plural subject `ellos` and intensify.  
4. Base: Hace calor. -> change to cold and add `hoy`.  
5. Base: El cafe esta caliente. -> intensify correctly.  
6. Base: La comida esta picante. -> change to very spicy.  
7. Base: Tengo 30 anos. -> change age to `54`.  
8. Base: Juan tiene 20 anos. -> make a yes/no question.  
9. Base: Tengo ganas de ir a la playa. -> change infinitive to `comer`.  
10. Base: Tienes ganas de salir? -> change subject to `ustedes`.  
11. Base: Tengo sueno. -> intensify.  
12. Base: Tengo prisa. -> make it negative.  
13. Base: Tengo suerte. -> change subject to `nosotros`.  
14. Base: Tengo la culpa. -> change to `tu` and negative.  
15. Base: El cuarto esta caliente. -> change to weather sentence with `hacer`.

## 7) common_errors

1. **Mistake:** `Estoy hambre.`  
   **Why it happens:** Direct translation of "I am hungry."  
   **Correct Spanish:** `Tengo hambre.`

2. **Mistake:** `Tengo muy hambre/sed.`  
   **Why it happens:** Using adjective intensifier with noun expression.  
   **Correct Spanish:** `Tengo mucha hambre/sed.`

3. **Mistake:** `Estoy frio` for personal feeling in this pattern set  
   **Why it happens:** Overusing `estar` for sensations.  
   **Correct Spanish:** `Tengo frio.`

4. **Mistake:** `Esta caliente hoy` for weather  
   **Why it happens:** Confusing weather with object temperature.  
   **Correct Spanish:** `Hace calor hoy.`

5. **Mistake:** `Tengo 30` without `anos` in beginner production  
   **Why it happens:** Copying English age format.  
   **Correct Spanish:** `Tengo 30 anos.`

6. **Mistake:** `Estoy ganas de...`  
   **Why it happens:** Literal "I am in the mood."  
   **Correct Spanish:** `Tengo ganas de + infinitive.`

7. **Mistake:** `Estoy sueno/prisa/suerte`  
   **Why it happens:** Treating fixed tener chunks like adjectives.  
   **Correct Spanish:** `Tengo sueno/prisa/suerte.`

8. **Mistake:** `El cafe tiene calor.`  
   **Why it happens:** Using personal-state verb for object property.  
   **Correct Spanish:** `El cafe esta caliente.`

9. **Mistake:** `La aguila` in singular  
   **Why it happens:** Ignoring stressed-a feminine noun article rule.  
   **Correct Spanish:** `El aguila` (but still feminine: `las aguilas`).

10. **Mistake:** `Hace muy calor.`  
    **Why it happens:** Mixing intensifiers.  
    **Correct Spanish:** `Hace mucho calor.`
