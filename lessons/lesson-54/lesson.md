# Spanish Daily Lesson 54: Cada Vez Patterns

## 1) cognitive_shift

**English trap**  
Using separate literal phrases for every time, more and more, and less and less, instead of one reusable Spanish pattern family.

**Spanish logic**  
`cada vez` is a high-frequency frame for repetition and gradual change.  
Use `cada vez que` for repeated events, and `cada vez + mas/menos/mejor/peor` for progression.

**target pattern / formula**  
- repetition: `cada vez que + verb, main clause`
- increase: `cada vez mas + noun/adjective/adverb`
- decrease: `cada vez menos + noun/adjective/adverb`
- progression quality: `cada vez mejor` / `cada vez peor`
- combo pattern: `cada vez que + action, result + cada vez mas/menos`

**5 natural examples**  
1. Cada vez que te veo, me rio.  
2. La ciudad esta cada vez mas cara.  
3. Tengo cada vez menos tiempo libre.  
4. Mi espanol esta cada vez mejor.  
5. Cada vez que practico, entiendo cada vez mas.

3. Base: Tengo cada vez menos tiempo libre. -> change noun to `energia`.  
4. Base: Mi espanol esta cada vez mejor. -> change to `peor`.

6. Base: Cada vez que viene Juan, termina quejandose. -> change subject to `Maria`.  
7. Base: Vemos a nuestros amigos cada vez menos. -> change adverb to `mas seguido`.  
8. Base: Cada vez hay mas gente aqui. -> change to decrease.  
9. Base: Cada vez que cocino, sale mejor. -> change verb to `trabajar`.  
10. Base: Duermo cada vez menos entre semana. -> change to first person plural.  
11. Base: Cada vez que hablamos, discutimos. -> make it positive result with `nos entendemos`.  
12. Base: El trafico esta cada vez mas pesado. -> change noun to `trabajo` and adjective to `intenso`.  
13. Base: Cada vez que practico, cometo menos errores. -> change object to `dudas`.

## 7) common_errors

1. **Mistake:** saying `cada vez` without `que` in event clauses  
   **Why it happens:** direct transfer from English "every time I...".  
   **Correct Spanish:** use `cada vez que + verb`.

2. **Mistake:** incorrect word order with `cada vez mas/menos`  
   **Why it happens:** literal ordering from English chunks.  
   **Correct Spanish:** keep `cada vez` directly before `mas/menos`.

3. **Mistake:** overusing progressive `estar + gerundio` where unnecessary  
   **Why it happens:** assuming all gradual change needs progressive.  
   **Correct Spanish:** `esta cada vez mas/menos/mejor/peor` is very natural.

4. **Mistake:** mixing `cada vez mas` with singular agreement errors  
   **Why it happens:** focus on chunk not noun agreement.  
   **Correct Spanish:** keep noun/adjective agreement consistent.

5. **Mistake:** using `cada vez que` for one-time events  
   **Why it happens:** confusion between repeated vs single event.  
   **Correct Spanish:** use it for repeated patterns.

6. **Mistake:** translating "better and better" as literal doubled adjective  
   **Why it happens:** direct translation strategy.  
   **Correct Spanish:** use `cada vez mejor`.

7. **Mistake:** translating "less and less" as repeated `menos menos`  
   **Why it happens:** forced word-for-word mapping.  
   **Correct Spanish:** use `cada vez menos`.

8. **Mistake:** forgetting second `cada vez` in combo sentences  
   **Why it happens:** cognitive overload in long sentences.  
   **Correct Spanish:** `cada vez que X, Y cada vez mas/menos`.

9. **Mistake:** using `cada vez` with no clear progression meaning  
   **Why it happens:** chunk inserted mechanically.  
   **Correct Spanish:** use when change over time is implied.

10. **Mistake:** avoiding this frame in conversation  
    **Why it happens:** low confidence with flexible chunks.  
    **Correct Spanish:** treat `cada vez` as a reusable template.
