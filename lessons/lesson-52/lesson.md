# Spanish Daily Lesson 52: Deber (Direct Obligation vs Soft Advice)

## 1) cognitive_shift

**English trap**  
Using one single "should" form and missing tone differences between advice and obligation.

**Spanish logic**  
Spanish uses tense choice with `deber` to control tone.  
Present (`debo/debes/debe...`) can sound like obligation or urgency.  
Conditional (`deberia/deberias/deberia...`) sounds softer and more like recommendation.

**target pattern / formula**  
- stronger/direct: `deber (presente) + infinitivo`
- softer advice: `deberia/deberias/deberiamos/deberian + infinitivo`
- self-talk pattern: `deberia + infinitivo`  
- add subject when needed for clarity: `yo deberia...` vs `usted deberia...`

**5 natural examples**  
1. Debes llamar ahora.  
2. Deberias llamar hoy.  
3. Yo deberia ordenar mi oficina.  
4. Deberiamos comer mas sano.  
5. Ustedes deberian salir mas temprano.

## 3) pattern_mutation

Transform each base sentence as instructed.

1. Base: Debes estudiar mas. -> make it softer advice to `tu`.  
2. Base: Yo deberia limpiar la casa. -> make it direct obligation.  
3. Base: Deberiamos salir temprano. -> change subject to `ellos`.  
4. Base: Debo llamar al banco. -> change to softer self-advice.  
5. Base: Deben pagar hoy. -> change to singular `el`.  
6. Base: Ella deberia descansar. -> change to plural `nosotros`.  
7. Base: Debes comer algo. -> make it formal `usted` soft advice.  
8. Base: Ustedes deberian llegar antes. -> make it direct obligation.  
9. Base: Yo deberia hacer cafe. -> change infinitive to `sacar la basura`.  
10. Base: Debemos terminar ahora. -> change to recommendation and add `pronto` instead of `ahora`.  
11. Base: El debe responder hoy. -> change to soft suggestion for tomorrow.  
12. Base: Yo deberia ordenar mi oficina. -> change noun to `cuarto`.  
13. Base: Deberian reciclar mas. -> change to first person plural recommendation.  
14. Base: Debes salir ya. -> change to negative soft advice (`not leave yet`).  
15. Base: Yo debo levantarme temprano. -> change to softer routine reflection.

## 4) contrastive_discrimination

Choose the better option for the intended meaning.

1. Soft advice to a friend: (Debes descansar. vs Deberias descansar.)  
2. Strict instruction from a manager: (Debes enviar el reporte hoy. vs Deberias enviar el reporte hoy.)  
3. Personal reflection, not command: (Yo debo organizarme mejor. vs Yo deberia organizarme mejor.)  
4. Gentle recommendation to a team: (Deben reunirse mas seguido. vs Deberian reunirse mas seguido.)  
5. Urgent rule right now: (Debes apagar eso ahora. vs Deberias apagar eso ahora.)  
6. Polite advice to a client: (Usted debe revisar este punto. vs Usted deberia revisar este punto.)  
7. Talking about healthy habits softly: (Debemos comer mejor. vs Deberiamos comer mejor.)  
8. Non-negotiable deadline: (Deben terminar hoy. vs Deberian terminar hoy.)  
9. Suggestion to yourself: (Debo acostarme mas temprano. vs Deberia acostarme mas temprano.)  
10. Softer proposal in a meeting: (Debemos cambiar la estrategia. vs Deberiamos cambiar la estrategia.)

## 7) common_errors

1. **Mistake:** using present `deber` for every "should"  
   **Why it happens:** English "should" has one surface form.  
   **Correct Spanish:** use conditional for softer advice.

2. **Mistake:** using conditional when giving strict instructions  
   **Why it happens:** fear of sounding direct.  
   **Correct Spanish:** present `deber` fits urgent obligation.

3. **Mistake:** translating soft self-talk as `tengo que` every time  
   **Why it happens:** overuse of one obligation chunk.  
   **Correct Spanish:** `deberia` is often more natural for reflection.

4. **Mistake:** forgetting infinitive after `deber/deberia`  
   **Why it happens:** trying to conjugate two verbs.  
   **Correct Spanish:** `deber + infinitivo`.

5. **Mistake:** confusion about who should do the action (`deberia`)  
   **Why it happens:** same form for yo/usted/el/ella.  
   **Correct Spanish:** add pronoun when needed (`yo deberia`, `usted deberia`).

6. **Mistake:** adding `que` after `deber`  
   **Why it happens:** mixing with other recommendation structures.  
   **Correct Spanish:** no `que`: `deberias estudiar`.

7. **Mistake:** using imperative when only advising  
   **Why it happens:** direct translation pressure.  
   **Correct Spanish:** choose `deberias` for polite suggestions.

8. **Mistake:** using weak tone in high-urgency context  
   **Why it happens:** over-politeness.  
   **Correct Spanish:** use present `debe/deben` when urgency is real.

9. **Mistake:** ignoring register with `usted`  
   **Why it happens:** focus on grammar over social tone.  
   **Correct Spanish:** `usted deberia...` sounds respectful.

10. **Mistake:** avoiding `deberia` in conversation  
    **Why it happens:** uncertainty with conditional forms.  
    **Correct Spanish:** practice `deberia + infinitivo` as a default advice frame.
