# Spanish Daily Lesson 20: The Personal "A" in Real Sentences

## 1) cognitive_shift

**English trap**  
Trying to translate directly and skipping `a` before people because English has no equivalent.

**Spanish logic**  
When a direct object is a person (or often a pet), Spanish usually requires the personal `a`.  
With non-specific people after verbs like `buscar`, `necesitar`, `contratar`, `encontrar`, `a` may be omitted.  
With `tener`, Spanish normally does **not** use personal `a`.

**target pattern / formula**  
- `ver/conocer/llamar/visitar/ayudar/respetar + a + person/pet`
- `buscar/necesitar/contratar + non-specific person` (often no `a`)
- `buscar/necesitar + specific person/group` -> use `a`
- `tener + person/pet` (normally no personal `a`)
- `a alguien / a nadie` usually takes personal `a`

**5 natural examples**  
1. Veo a Marta en la entrada.  
2. Buscamos un tecnico para el turno de noche.  
3. Necesitamos a los tecnicos que conocen este sistema.  
4. Tengo dos hijas y un perro.  
5. No conozco a nadie en esa empresa.

## 3) pattern_mutation

Transform each base sentence as instructed.

1. Base: Veo a Juan. -> change object to inanimate plural (`las casas`).  
2. Base: Conozco a Maria. -> make it negative.  
3. Base: Ayudamos a nuestro vecino. -> change to singular subject `yo`.  
4. Base: Buscamos un profesor. -> make the professor specific (`que conocemos`).  
5. Base: Necesitan empleados. -> make employees specific (`que conocen el sistema`).  
6. Base: Tengo dos hijos. -> change verb to `conocer` and keep meaning as close as possible.  
7. Base: Llamo a mi hermana. -> change tense to preterite `yo`.  
8. Base: Visitan a sus abuelos. -> make it a yes/no question with `ustedes`.  
9. Base: Respetamos a nuestros maestros. -> change to `ellos`.  
10. Base: Veo a mi perro. -> change pet to non-pet animal plural (`delfines`).  
11. Base: No conozco a nadie aqui. -> change to affirmative with `alguien`.  
12. Base: Contratamos a la ingeniera que ya conociamos. -> make object non-specific.  
13. Base: Buscas a tu jefe. -> make it progressive (`estar + gerundio`) with `tu`.  
14. Base: Ayudan a su cliente. -> make it negative and plural object (`clientes`).  
15. Base: Encuentro a Carlos en la recepcion. -> change person object to object thing (`el informe`).

1. I see Sofia. (`Veo a Sofia.` vs `Veo Sofia.`)

## 7) common_errors

1. **Mistake:** `Veo Juan.`  
   **Why it happens:** English transfer; no marker before person in English.  
   **Correct Spanish:** `Veo a Juan.`

2. **Mistake:** `Veo a las oficinas.`  
   **Why it happens:** Overgeneralizing personal `a` to all objects.  
   **Correct Spanish:** `Veo las oficinas.`

3. **Mistake:** `Buscamos a un profesor.` (non-specific) always used automatically  
   **Why it happens:** Learner assumes every person needs `a` in all contexts.  
   **Correct Spanish:** `Buscamos un profesor.` (non-specific), `Buscamos a un profesor que conocemos.` (specific)

4. **Mistake:** `Necesitamos los empleados que conocen el sistema.`  
   **Why it happens:** Missing `a` with specific known people.  
   **Correct Spanish:** `Necesitamos a los empleados que conocen el sistema.`

5. **Mistake:** `Tengo a dos hijos.`  
   **Why it happens:** Applying personal `a` to `tener`.  
   **Correct Spanish:** `Tengo dos hijos.`

6. **Mistake:** `No conozco nadie.`  
   **Why it happens:** Omitting `a` before `nadie`.  
   **Correct Spanish:** `No conozco a nadie.`

7. **Mistake:** `Conozco a las casas de ese barrio.`  
   **Why it happens:** Confusing animate vs inanimate object rules.  
   **Correct Spanish:** `Conozco las casas de ese barrio.`

8. **Mistake:** `Invito su hermana.`  
   **Why it happens:** Forgetting direct object is a person.  
   **Correct Spanish:** `Invito a su hermana.`

9. **Mistake:** `Ayudamos nuestros clientes.`  
   **Why it happens:** Copying English object structure.  
   **Correct Spanish:** `Ayudamos a nuestros clientes.`

10. **Mistake:** Treating every `a` as personal `a`  
    **Why it happens:** Sentences can contain multiple `a` forms (`ir a`, destination, personal `a`).  
    **Correct Spanish:** Analyze role: `Voy a invitar a mi hermano a la fiesta.`
