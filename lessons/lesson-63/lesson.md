# Spanish Daily Lesson 63: Redundant Indirect Object `le/les`

## 1) cognitive_shift

**English trap**  
Dropping `le/les` when the recipient is already named because it feels repetitive.

**Spanish logic**  
With many high-frequency verbs, Spanish naturally keeps the indirect object pronoun (`le/les`) even when `a + person` is present.  
The pronoun is expected in real speech.

**target pattern / formula**  
- core frame: `le/les + verb + direct object + a + person`
- singular recipient: `le`
- plural recipients: `les`
- named recipient can be omitted, but pronoun usually stays
- frequent verbs: `dar`, `decir`, `contar`, `comprar`, `traer`, `mandar/enviar`, `pedir`, `robar`, `quitar`, `prestar`, `devolver`

**5 natural examples**  
1. Le di el libro a Juan.  
2. Le dije la verdad a Maria.  
3. Le mande una carta a Pedro.  
4. Les prestamos el coche a mis vecinos.  
5. Le quitaron el telefono a Marta.

## 7) common_errors

1. **Mistake:** dropping `le/les` when recipient is named  
   **Why it happens:** English does not duplicate this structure.  
   **Correct Spanish:** keep redundant pronoun with common indirect-object verbs.

2. **Mistake:** using `lo/la` instead of `le/les` for recipient  
   **Why it happens:** direct vs indirect object confusion.  
   **Correct Spanish:** recipient is indirect object, so use `le/les`.

3. **Mistake:** using `les` with singular recipient  
   **Why it happens:** pronoun-number mismatch.  
   **Correct Spanish:** `le` for one recipient, `les` for multiple.

4. **Mistake:** assuming every verb needs redundant `le`  
   **Why it happens:** overgeneralizing one pattern.  
   **Correct Spanish:** use it with high-frequency verbs that naturally take indirect objects.

5. **Mistake:** wrong word order around pronoun and verb  
   **Why it happens:** translating from English order.  
   **Correct Spanish:** place clitic pronoun before conjugated verb.

6. **Mistake:** omitting personal `a` with human recipient  
   **Why it happens:** article-based translation habits.  
   **Correct Spanish:** keep `a + person` when naming recipient.

7. **Mistake:** not using `les` in plural context  
   **Why it happens:** chunk memorized as only `le`.  
   **Correct Spanish:** adjust pronoun by recipient number.

8. **Mistake:** treating redundancy as optional in formal speech  
   **Why it happens:** stylistic over-editing.  
   **Correct Spanish:** in natural Spanish this redundancy is highly expected.

9. **Mistake:** mixing recipient and source meaning with `comprar`  
   **Why it happens:** verb can be ambiguous without context.  
   **Correct Spanish:** keep context clear and use full sentence.

10. **Mistake:** avoiding this pattern in conversation  
    **Why it happens:** fear of sounding repetitive.  
    **Correct Spanish:** this repetition sounds normal and fluent in Spanish.
