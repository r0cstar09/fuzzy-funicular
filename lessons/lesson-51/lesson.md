# Spanish Daily Lesson 51: Time Clauses That Trigger Subjunctive

## 1) cognitive_shift

**English trap**  
Using present tense after "when/as soon as/once" for all situations, without separating routine facts from future-dependent actions.

**Spanish logic**  
When one action must happen first and that action is still pending (future or command context), Spanish uses subjunctive in the time clause.  
If it is a routine/habit, Spanish uses indicative.  
`antes de que` always triggers subjunctive.

**target pattern / formula**  
- future/command dependence: `main clause (future/imperative) + cuando/en cuanto/una vez que + subjuntivo`
- habitual routine: `main clause (habitual) + cuando/en cuanto/una vez que + indicativo`
- always: `antes de que + subjuntivo`
- past narration dependence: `main past trigger + cuando + imperfecto de subjuntivo`

**5 natural examples**  
1. Avisame cuando tengas la informacion.  
2. Cenaremos cuando Juan llegue.  
3. En cuanto reciba tu mensaje, te llamo.  
4. Siempre ceno cuando termino de trabajar.  
5. Limpio la cocina antes de que lleguen los invitados.

## 3) pattern_mutation

Transform each base sentence as instructed.

1. Base: Te llamo cuando termine. -> change connector to `en cuanto`.  
2. Base: Te llamo en cuanto termine. -> change connector to `una vez que`.  
3. Base: Cenaremos cuando llegue Ana. -> change to command with `avisame`.  
4. Base: Avisame cuando tengas tiempo. -> change to plural `avisenme`.  
5. Base: Empezaremos cuando llegue el jefe. -> change to first person singular future.  
6. Base: Siempre cenamos cuando termina el trabajo. -> change subject to `yo`.  
7. Base: Suelo descansar cuando termino de trabajar. -> change verb `descansar` to `leer`.  
8. Base: Limpio la casa antes de que llegue Juan. -> change subject of second clause to plural.  
9. Base: Antes de que firmes, lee todo. -> change command to plural `lean`.  
10. Base: Te avise cuando llegue. -> change to past narration with imperfect subjunctive in both clauses.  
11. Base: Le dije que me llamara cuando saliera. -> change pronoun to `nos`.  
12. Base: En cuanto reciba la confirmacion, reservare. -> change main clause to present command `reserva`.  
13. Base: Siempre salimos cuando deja de llover. -> change to future-dependent event.  
14. Base: Nos iremos cuando deje de llover. -> change to habitual routine.  
15. Base: Te escribo cuando tenga noticias. -> make it habitual with `siempre` and adjust mood.

## 7) common_errors

1. **Mistake:** using indicative after `cuando` for future events  
   **Why it happens:** direct English transfer.  
   **Correct Spanish:** use subjunctive for pending future-dependent actions.

2. **Mistake:** using subjunctive in habitual routines  
   **Why it happens:** overgeneralizing trigger words.  
   **Correct Spanish:** habitual/repeated events use indicative.

3. **Mistake:** treating `en cuanto` as always indicative  
   **Why it happens:** translated as simple "as soon as" without mood logic.  
   **Correct Spanish:** future/command context takes subjunctive.

4. **Mistake:** using indicative after `antes de que`  
   **Why it happens:** assuming the same rule as `cuando`.  
   **Correct Spanish:** `antes de que` always takes subjunctive.

5. **Mistake:** wrong tense in past narration (`cuando llega` with past main clause)  
   **Why it happens:** not applying sequence of tenses.  
   **Correct Spanish:** use imperfect subjunctive (`cuando llegara`).

6. **Mistake:** infinitive after `cuando` without subject shift  
   **Why it happens:** confusion with `antes de + infinitivo` patterns.  
   **Correct Spanish:** use finite verb with correct mood (`cuando tengas...`).

7. **Mistake:** choosing mood by connector only  
   **Why it happens:** memorizing word list without context.  
   **Correct Spanish:** decide by meaning: habitual vs pending/commanded.

8. **Mistake:** keeping present subjunctive after past command  
   **Why it happens:** incomplete past-subjunctive control.  
   **Correct Spanish:** past trigger usually requires imperfect subjunctive.

9. **Mistake:** dropping `que` in `una vez que`  
   **Why it happens:** literal chunk transfer.  
   **Correct Spanish:** keep full connector `una vez que`.

10. **Mistake:** using future tense in subordinate clause (`cuando llegara` as future intent in modern speech confusion)  
    **Why it happens:** uncertainty between forms.  
    **Correct Spanish:** use present subjunctive for future dependence (`cuando llegue`).
