# Spanish Daily Lesson 36: Que Tal for Check-ins and Suggestions

## 1) cognitive_shift

**English trap**  
Trying to build full "How is/was...?" questions with extra verbs every time.

**Spanish logic**  
`Que tal + noun` is a fast native frame for "How is/was ...?" and context carries tense.  
`Que tal si + present` is a simple suggestion pattern for "How about we ...?"

**target pattern / formula**  
- `que tal + noun`  
- `que tal + possessive + noun`  
- `que tal si + present nosotros`  
- short response chunks: `bien`, `muy bien`, `regular`, `fatal`

**5 natural examples**  
1. Que tal la comida?  
2. Que tal tu dia?  
3. Que tal el concierto?  
4. Que tal si vamos en taxi?  
5. Que tal si practicamos espanol?

## 3) pattern_mutation

Transform each base sentence as instructed.

1. Base: Que tal la comida? -> change noun to `la reunion`.  
2. Base: Que tal tu dia? -> change possessive to `tu semana`.  
3. Base: Que tal el concierto? -> change noun to plural `los conciertos`.  
4. Base: Que tal la clase? -> change noun to `el curso`.  
5. Base: Que tal si vamos a la playa? -> change destination to `el centro`.  
6. Base: Que tal si nos quedamos en casa? -> change to `salimos a cenar`.  
7. Base: Que tal si practicamos espanol? -> change activity to `revisamos el informe`.  
8. Base: Que tal si tomamos un taxi? -> change transport to `el metro`.  
9. Base: Que tal si cocinamos algo? -> make it negative suggestion.  
10. Base: Que tal si invitamos a Ana? -> change person to plural `a tus amigos`.  
11. Base: Que tal la sopa? -> change noun to `el cafe`.  
12. Base: Que tal si cancelamos la reservacion? -> change verb to `confirmamos`.  
13. Base: Que tal el hotel? -> change to past-context noun `el viaje`.  
14. Base: Que tal si vemos una pelicula? -> change object to `una serie`.  
15. Base: Que tal la cena? -> turn into suggestion with same noun.

## 7) common_errors

1. **Mistake:** `Como tal la comida?`  
   **Why it happens:** Mixing two question starters.  
   **Correct Spanish:** `Que tal la comida?`

2. **Mistake:** `Que tal es la comida?`  
   **Why it happens:** Adding unnecessary verb in this fixed frame.  
   **Correct Spanish:** `Que tal la comida?`

3. **Mistake:** `Que tal si vamos?` with subjunctive (`vayamos`) every time  
   **Why it happens:** Overapplying formal suggestion grammar.  
   **Correct Spanish:** `Que tal si vamos...?` is natural and simple.

4. **Mistake:** `Que tal vamos a la playa?`  
   **Why it happens:** Forgetting `si` in suggestion pattern.  
   **Correct Spanish:** `Que tal si vamos a la playa?`

5. **Mistake:** Translating tense literally with `fue/esta` in all cases  
   **Why it happens:** Word-for-word tense mapping.  
   **Correct Spanish:** `Que tal + noun` lets context show present or past.

6. **Mistake:** `Que tal si ir a la tienda?`  
   **Why it happens:** Using infinitive after `si`.  
   **Correct Spanish:** `Que tal si vamos a la tienda?`

7. **Mistake:** `Que tal tu dia es?`  
   **Why it happens:** English word order transfer.  
   **Correct Spanish:** `Que tal tu dia?`

8. **Mistake:** `Que tal si nos quedamos en casa hoy?` as a statement only  
   **Why it happens:** Forgetting intonation/question marks in writing.  
   **Correct Spanish:** `Que tal si nos quedamos en casa hoy?`

9. **Mistake:** `Que tal de la cena?`  
   **Why it happens:** Adding extra preposition from English habits.  
   **Correct Spanish:** `Que tal la cena?`

10. **Mistake:** Avoiding short responses  
    **Why it happens:** Belief that full sentences are always required.  
    **Correct Spanish:** Short replies like `bien`, `regular`, `fatal` are natural.
