# Spanish Daily Lesson 66: Por vs Para Decision Frames

## 1) cognitive_shift

**English trap**  
Translating both `por` and `para` as `for` without checking function.

**Spanish logic**  
Pick the preposition by meaning role: `para` points forward to goal or destination, `por` points backward to reason, method, exchange, or path.

**target pattern / formula**  
- `para + infinitive` for purpose  
- `para + person` for recipient/benefit  
- `para + date/time` for deadline  
- `por + noun` for cause/reason  
- `por + duration/means/path/exchange`

**5 natural examples**  
1. Estudio espanol para trabajar con clientes globales.  
2. Sali para la oficina a las siete.  
3. Necesito el informe para el viernes.  
4. No fuimos por la lluvia.  
5. Viajamos por tren y pagamos poco por los boletos.

## 7) common_errors

1. **Mistake:** `Estoy estudiando por mejorar mi espanol`  
   **Why it happens:** Purpose with infinitive is mapped to `por` from English `for`.  
   **Correct Spanish:** `Estoy estudiando para mejorar mi espanol.`

2. **Mistake:** `Gracias para tu ayuda`  
   **Why it happens:** Set expression is translated literally.  
   **Correct Spanish:** `Gracias por tu ayuda.`

3. **Mistake:** `Necesito el reporte por el viernes`  
   **Why it happens:** Deadline meaning is confused with cause.  
   **Correct Spanish:** `Necesito el reporte para el viernes.`

4. **Mistake:** `No fuimos para la lluvia`  
   **Why it happens:** Cause/reason context incorrectly uses `para`.  
   **Correct Spanish:** `No fuimos por la lluvia.`

5. **Mistake:** `Viajamos para tren`  
   **Why it happens:** Means of transport pattern is unknown.  
   **Correct Spanish:** `Viajamos por tren.`

6. **Mistake:** `Me quede para dos horas`  
   **Why it happens:** Duration in past is marked with wrong preposition.  
   **Correct Spanish:** `Me quede por dos horas.`

7. **Mistake:** `Pague mucho para ese coche`  
   **Why it happens:** Price/exchange is mixed with purpose.  
   **Correct Spanish:** `Pague mucho por ese coche.`

8. **Mistake:** `Trabajo por Google` (when employer meaning is intended)  
   **Why it happens:** Employer and motive meanings are not separated.  
   **Correct Spanish:** `Trabajo para Google.`

9. **Mistake:** `Entro para la puerta trasera`  
   **Why it happens:** Movement through a place uses `por`, not `para`.  
   **Correct Spanish:** `Entro por la puerta trasera.`

10. **Mistake:** `Lo hice para amor`  
    **Why it happens:** Motive expressions are overgeneralized to `para`.  
    **Correct Spanish:** `Lo hice por amor.`
