# Spanish Daily Lesson 61: Ir vs Irse vs Salir

## 1) cognitive_shift

**English trap**  
Using one single verb for "go/leave" and translating directly from English.

**Spanish logic**  
Spanish separates movement meanings by focus:
- `ir` focuses on destination
- `irse` emphasizes departure or heading out
- `salir` emphasizes exiting, going out, release, or how something turned out

**target pattern / formula**  
- destination focus: `ir + a + lugar`
- departure focus: `irse` (`me voy`, `se fue`)
- exit origin: `salir de + lugar`
- social/action: `salir a + infinitive`, `salir con + persona`
- result/outcome: `me/te/le salio bien/mal/dificil`

**5 natural examples**  
1. Voy a la oficina.  
2. Ya me voy.  
3. Salgo de casa a las ocho.  
4. Quieres salir a cenar?  
5. La entrevista me salio bien.

## 3) pattern_mutation

Transform each base sentence as instructed.

1. Base: Voy a la tienda. -> change destination to `el banco`.  
2. Base: Me voy ahora. -> change subject to plural `nosotros`.  
3. Base: Salgo de la casa a las ocho. -> change place to `la oficina`.  
4. Base: Maria se fue a Estados Unidos. -> change destination to `Espana`.  
5. Base: Quieres salir a cenar? -> change infinitive to `caminar`.  
6. Base: Mi ex sale con mi mejor amigo. -> change subject to plural `mis amigos`.  
7. Base: Cuanto tiempo llevan saliendo? -> change to singular `ella` with `tu primo`.  
8. Base: La nueva pelicula sale en junio. -> change month to `septiembre`.  
9. Base: El informe salio mejor de lo esperado. -> change adjective to `peor`.  
10. Base: El examen me salio dificil. -> change pronoun to `nos`.  
11. Base: Como te salio la entrevista? -> change noun to `presentacion`.  
12. Base: Vete. -> change to formal imperative positive.  
13. Base: No te vayas. -> change to formal negative command.  
14. Base: Se va ahora. -> change to first person singular.  
15. Base: Salimos a cenar esta noche. -> change to yesterday past form.

1. I am going to the office. (`Voy a la oficina.` vs `Me voy la oficina.`)

10. How did the meeting go for you? (`Como te salio la reunion?` vs `Como te fue la reunion?`)

## 7) common_errors

1. **Mistake:** using `ir` when meaning "leave now"  
   **Why it happens:** English uses go in both senses.  
   **Correct Spanish:** use `irse` for heading out/departure.

2. **Mistake:** using `irse` without reflexive pronoun  
   **Why it happens:** pronominal pattern not internalized.  
   **Correct Spanish:** keep pronoun (`me voy`, `se van`).

3. **Mistake:** using `salir` for all movement contexts  
   **Why it happens:** overgeneralization from "leave."  
   **Correct Spanish:** choose by focus: destination, departure, or exit/result.

4. **Mistake:** saying `voy de la casa` for habitual departure  
   **Why it happens:** literal transfer.  
   **Correct Spanish:** use `salgo de la casa`.

5. **Mistake:** confusing `salir a + infinitive` with `ir a + infinitive`  
   **Why it happens:** both can involve future/action meaning.  
   **Correct Spanish:** `salir a` means go out to do something.

6. **Mistake:** missing `con` in dating meaning  
   **Why it happens:** translating "date someone" directly.  
   **Correct Spanish:** use `salir con alguien`.

7. **Mistake:** avoiding outcome use `me salio...`  
   **Why it happens:** learners only know movement meaning of `salir`.  
   **Correct Spanish:** use indirect pronoun + `salir` for how it went.

8. **Mistake:** wrong command forms for `irse`  
   **Why it happens:** imperative + pronoun placement confusion.  
   **Correct Spanish:** `vete`, `vayase`, `no te vayas`, `no se vaya`.

9. **Mistake:** using `ir` for media releases  
   **Why it happens:** English "comes/goes out" ambiguity.  
   **Correct Spanish:** use `salir` for release dates.

10. **Mistake:** treating `fue` and `salio` as interchangeable outcomes  
    **Why it happens:** both can describe events loosely.  
    **Correct Spanish:** `me salio bien/mal` is a high-frequency result frame.
