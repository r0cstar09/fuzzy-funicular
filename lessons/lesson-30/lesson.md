# Spanish Daily Lesson 30: Por vs Para in Real Sentences

## 1) cognitive_shift

**English trap**  
Using one English word "for" and guessing between `por` and `para`.

**Spanish logic**  
Spanish splits functions:
- `para` = purpose, destination, deadline, recipient/benefit
- `por` = cause, motive, exchange, movement through, duration, done on behalf of

**target pattern / formula**  
- Purpose: `para + infinitive` (`para estudiar`)  
- Destination/recipient: `para Madrid`, `para Maria`  
- Cause/motive: `por amor`, `por la noticia`  
- Through/duration: `por el parque`, `por tres horas`  
- New subject purpose: `para que + subjuntivo`

**5 natural examples**  
1. Trabajo mucho para ahorrar dinero.  
2. Gracias por tu ayuda.  
3. Salimos para Madrid manana.  
4. Caminamos por el centro.  
5. Hablo despacio para que me entiendas.

## 7) common_errors

1. **Mistake:** `Trabajo por una empresa` (employee meaning)  
   **Why it happens:** English "work for" maps to one preposition.  
   **Correct Spanish:** `Trabajo para una empresa.`

2. **Mistake:** `Gracias para...`  
   **Why it happens:** Overusing `para` for all "for".  
   **Correct Spanish:** `Gracias por...`

3. **Mistake:** `Necesito esto por manana` (deadline)  
   **Why it happens:** Confusing duration/cause with deadline use.  
   **Correct Spanish:** `Necesito esto para manana.`

4. **Mistake:** `Voy por Madrid` when destination is intended  
   **Why it happens:** Mixing through with toward/destination.  
   **Correct Spanish:** `Voy para Madrid.`

5. **Mistake:** `Estudio por aprender`  
   **Why it happens:** Missing purpose rule with infinitive.  
   **Correct Spanish:** `Estudio para aprender.`

6. **Mistake:** `Lo compre por ti` when recipient meaning is intended  
   **Why it happens:** Not separating recipient vs cause/substitution.  
   **Correct Spanish:** `Lo compre para ti.`

7. **Mistake:** `Hablo despacio por que entiendas`  
   **Why it happens:** Spelling and structure confusion with purpose clause.  
   **Correct Spanish:** `Hablo despacio para que entiendas.`

8. **Mistake:** `Camine para el parque` when meaning is through/around  
   **Why it happens:** Using destination preposition for route.  
   **Correct Spanish:** `Camine por el parque.`

9. **Mistake:** `Pague la casa por 300` missing context  
   **Why it happens:** Not knowing when `por` is required with `pagar`.  
   **Correct Spanish:** `Pague 300 por la casa.` when amount is separated.

10. **Mistake:** Trying to memorize one global rule  
    **Why it happens:** Por/para are category-based, not one-rule items.  
    **Correct Spanish:** Choose by function: purpose/destination (`para`) vs cause/through/duration (`por`).
