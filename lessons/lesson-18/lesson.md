# Spanish Daily Lesson 18 (Writing-First)

## 1) cognitive_shift

- **English trap:** Building “gave it to her” word-by-word and placing pronouns in English order.
- **Spanish logic:** With double-object pronouns, Spanish follows a fixed sequence: **indirect pronoun + direct pronoun + verb**. Also, `le/les` changes to `se` before `lo/la/los/las`.
- **target pattern/formula:**
  - `IO + DO + preterite of dar`
  - `le/les + lo/la/los/las -> se + lo/la/los/las`
  - Optional clarifier still possible: `Se lo di a María.`

### 5 natural examples
1. Se lo di.  
2. Te los di.  
3. Me la diste.  
4. Se las dieron.  
5. ¿Se lo diste a tu mamá?

## 3) pattern_mutation

Transform each base sentence as instructed.

1. Base: `Le di el libro a María.` -> rewrite only with pronouns.  
2. Base: `Les dimos las llaves a ellos.` -> rewrite only with pronouns.  
3. Base: `Te di el dinero.` -> change direct object to plural (`los boletos`).  
4. Base: `Me diste la receta.` -> change subject to `nosotros`.  
5. Base: `Se lo dio.` -> change direct object to feminine singular.  
6. Base: `Se la dimos.` -> change indirect recipient from third person to `te`.  
7. Base: `Nos lo dieron.` -> change direct object to feminine plural.  
8. Base: `Te las di.` -> make it a yes/no question.  
9. Base: `Se los diste.` -> change tense person to `yo` preterite.

## 7) common_errors

1. **Using `le lo` / `les la` combos**  
   Why: Learner keeps literal pronouns.  
   Correct: `se lo`, `se la`, `se los`, `se las`.
2. **Wrong pronoun order (`lo me dio`)**  
   Why: English order transfer.  
   Correct: `me lo dio` (IO -> DO -> verb).
3. **Dropping indirect pronoun when clarifier exists**  
   Why: “a Juan” seems enough.  
   Correct: `Le di el libro a Juan.`
4. **Using direct pronoun only in double-object context**  
   Why: Partial mapping from English object structure.  
   Correct: include both when both are present.
5. **Confusing recipient and thing pronouns**  
   Why: Role tracking error.  
   Correct: recipient = `me/te/le/nos/les`; thing = `lo/la/los/las`.
6. **Forgetting gender/number in direct pronoun**  
   Why: English “it/them” neutralization.  
   Correct: `la` receta, `los` boletos, etc.
7. **Using present verb with past meaning**  
   Why: Pronoun load causes tense drift.  
   Correct: `di/diste/dio...` for preterite practice.
8. **Misreading `se` as reflexive here**  
   Why: `se` has many uses.  
   Here: it replaces `le/les` before DO pronoun.
9. **Attaching pronouns to conjugated finite verb incorrectly**  
   Why: Mixing with infinitive/command rules.  
   In this lesson core: keep before conjugated preterite.
10. **Skipping repetition practice due to complexity**  
    Why: Pattern feels unnatural at first.  
    Fix: drill short frames (`se lo di`, `te la dio`) daily.
