# Spanish Daily Lesson 38: Commands That Sound Natural

## 1) cognitive_shift

**English trap**  
Trying to express commands with future or modal phrases ("you should...", "you will...") instead of direct command forms.

**Spanish logic**  
Spanish uses dedicated imperative forms by addressee (`tu`, `usted`, `ustedes`, `nosotros`) and by polarity (affirmative/negative). Pronoun position changes with command polarity.

**target pattern / formula**  
- `tu` affirmative: present `el/ella` form (or irregular: `haz, di, ve, pon, sal, se, ten, ven`)  
- `tu` negative: `no + subjunctive`  
- `usted/ustedes` commands: subjunctive forms  
- `nosotros` command: subjunctive (`comamos`, `no comamos`)  
- pronouns: affirmative attach (`damelo`), negative before verb (`no me lo des`)  
- RID pronoun order: reflexive -> indirect -> direct

**5 natural examples**  
1. Pon la mesa, por favor.  
2. No salgas sin chaqueta.  
3. Senor, espere aqui un momento.  
4. Apaguen sus telefonos, por favor.  
5. Digamos la verdad hoy.

## 7) common_errors

1. **Mistake:** `No hazlo.`  
   **Why it happens:** Using affirmative form after `no`.  
   **Correct Spanish:** `No lo hagas.`

2. **Mistake:** `No hagaslo.`  
   **Why it happens:** Keeping pronoun attached in negative commands.  
   **Correct Spanish:** `No lo hagas.`

3. **Mistake:** `Diga` when talking to a close friend  
   **Why it happens:** Mixing `usted` and `tu` registers.  
   **Correct Spanish:** Use `di` for informal `tu`.

4. **Mistake:** `No sentate.`  
   **Why it happens:** Using affirmative reflexive shape in negative command.  
   **Correct Spanish:** `No te sientes.`

5. **Mistake:** `Lo di` as command  
   **Why it happens:** Confusing past tense with imperative.  
   **Correct Spanish:** `Dilo.`

6. **Mistake:** Wrong pronoun order (`lo me das`)  
   **Why it happens:** Translating English order.  
   **Correct Spanish:** `damelo` / `no me lo des`.

7. **Mistake:** `No vayasen`  
   **Why it happens:** Incorrect subjunctive formation for ustedes.  
   **Correct Spanish:** `No se vayan.`

8. **Mistake:** Forgetting accent in attached-pronoun commands  
   **Why it happens:** Spelling omission after clitic attachment.  
   **Correct Spanish:** `traigamelo`, `digamelo`, `pongasela` (with proper stress/orthography).

9. **Mistake:** Using infinitive for commands (`esperar aqui`)  
   **Why it happens:** English instruction style transfer.  
   **Correct Spanish:** `Espere aqui.`

10. **Mistake:** Avoiding `nosotros` command form  
    **Why it happens:** Overusing `vamos a` only.  
    **Correct Spanish:** `comamos`, `no comamos`, and also `vamos a...` when appropriate.
