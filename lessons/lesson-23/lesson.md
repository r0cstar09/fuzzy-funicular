# Spanish Daily Lesson 23: How Long, Since When, and How Long Ago

## 1) cognitive_shift

**English trap**  
Trying to map "for/since/ago" one-to-one and using one English structure for every timeline idea.

**Spanish logic**  
Spanish separates timeline meaning into different frames:  
- **how long ago** (`hace + tiempo + preterite`)  
- **since a start point** (`presente + desde + punto`)  
- **for a duration up to now** (`presente + desde hace + duracion`)  
- plus two common alternatives: `hace + tiempo + que + presente` and `llevar + tiempo + gerundio`.

**target pattern / formula**  
- `hace + time expression + preterite`  
- `present tense + desde + specific point`  
- `present tense + desde hace + duration`  
- `hace + duration + que + present tense`  
- `llevar + duration + gerundio`

**5 natural examples**  
1. Llegue aqui hace tres anos.  
2. Vivo en esta ciudad desde 2021.  
3. Trabajo remoto desde hace dos anos.  
4. Hace seis meses que estudio contabilidad.  
5. Llevo veinte minutos esperando al cliente.

## 3) pattern_mutation

Transform each base sentence as instructed.

1. Base: Llegue hace dos anos. -> change duration to `cinco anos`.  
2. Base: Ella llamo hace tres dias. -> change subject to `nosotros`.  
3. Base: Vivo aqui desde 2020. -> change start point to `2018`.  
4. Base: Trabajo aqui desde enero. -> change month to `septiembre`.  
5. Base: Estudio espanol desde hace seis meses. -> change to `dos anos`.  
6. Base: Esperamos desde hace una hora. -> change subject to `yo`.  
7. Base: Hace dos horas que estudio. -> change to negative.  
8. Base: Hace tres anos que vivimos aqui. -> change subject to `ellos`.  
9. Base: Llevo dos anos trabajando aqui. -> change subject to `ella`.  
10. Base: Llevamos veinte minutos esperando. -> change duration to `una hora`.  
11. Base: Tengo este coche desde el verano pasado. -> rewrite with `desde hace` and a duration.  
12. Base: Conozco a Ana desde 2019. -> rewrite with `desde hace` and duration.  
13. Base: Hace un mes que compro cafe aqui. -> rewrite with `llevar + gerundio`.  
14. Base: Llegaron hace una semana. -> turn into yes/no question.  
15. Base: Trabajo aqui desde hace cuatro anos. -> rewrite with `hace + duration + que`.

## 7) common_errors

1. **Mistake:** `Vivo aqui hace tres anos.`  
   **Why it happens:** Direct translation from "I live here for three years."  
   **Correct Spanish:** `Vivo aqui desde hace tres anos.`

2. **Mistake:** `Llegue desde hace dos anos.`  
   **Why it happens:** Mixing "ago" with ongoing duration structure.  
   **Correct Spanish:** `Llegue hace dos anos.`

3. **Mistake:** `Trabajo aqui desde cinco anos.`  
   **Why it happens:** Missing `hace` with duration after `desde`.  
   **Correct Spanish:** `Trabajo aqui desde hace cinco anos.`

4. **Mistake:** `Desde cuando estas aqui?` answered with `desde hace 2020`  
   **Why it happens:** Confusing point-in-time vs duration.  
   **Correct Spanish:** `desde 2020` (point), `desde hace tres anos` (duration).

5. **Mistake:** `Hace dos horas estudio.` for ongoing meaning  
   **Why it happens:** Missing `que` in alternate ongoing frame.  
   **Correct Spanish:** `Hace dos horas que estudio.`

6. **Mistake:** `Llevo dos anos trabajo aqui.`  
   **Why it happens:** Using finite verb instead of gerund after `llevar`.  
   **Correct Spanish:** `Llevo dos anos trabajando aqui.`

7. **Mistake:** `Lo conoci desde hace cinco anos.`  
   **Why it happens:** Mixing completed past with ongoing reference.  
   **Correct Spanish:** `Lo conozco desde hace cinco anos.`

8. **Mistake:** `Tengo este coche hace enero.`  
   **Why it happens:** Using `hace` with a calendar point.  
   **Correct Spanish:** `Tengo este coche desde enero.`

9. **Mistake:** `Desde cuando trabajas?` with no accent marks or full frame in formal writing  
   **Why it happens:** Dropping fixed question chunk details.  
   **Correct Spanish:** `Desde cuando trabajas aqui?` (practice full chunk).

10. **Mistake:** Using one pattern for all time meanings  
    **Why it happens:** Learner overgeneralizes first formula learned.  
    **Correct Spanish:** Pick by meaning: ago (`hace + preterite`), since-point (`desde`), for-duration (`desde hace` / `llevar`).
