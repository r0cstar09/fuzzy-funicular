# Spanish Daily Lesson 48: Para Que for Purpose and Intent

## 1) cognitive_shift

**English trap**  
Using one generic "to + verb" translation for every purpose sentence.

**Spanish logic**  
Spanish separates purpose into two structures:
- `para + infinitivo` when the subject stays the same  
- `para que + subjuntivo` when the subject changes  
If the main clause is in past and the result is "so that ... would ...", use imperfect subjunctive.

**target pattern / formula**  
- same subject: `para + infinitive`  
- subject change (present/future): `para que + present subjunctive`  
- subject change (past main clause): `para que + imperfect subjunctive`  
- command + purpose: command, then `para que + subjunctive`

**5 natural examples**  
1. Trabajo todos los dias para ahorrar dinero.  
2. Hago videos para que mejores tu espanol.  
3. Cierra la puerta para que el gato no se escape.  
4. Pinte la casa para que se vendiera mas rapido.  
5. Le explique todo para que supiera la verdad.

1. I study to learn. (`Estudio para aprender.` vs `Estudio para que aprenda.`)

7. Turn on the light so that we can read. (`Enciende la luz para que podamos leer.` vs `Enciende la luz para leer podamos.`)

## 7) common_errors

1. **Mistake:** always using `para + infinitivo`  
   **Why it happens:** direct English "to + verb" transfer.  
   **Correct Spanish:** use `para que + subjuntivo` when subjects differ.

2. **Mistake:** `para que` with same subject  
   **Why it happens:** overgeneralizing trigger phrase.  
   **Correct Spanish:** same subject -> `para + infinitivo`.

3. **Mistake:** `para que` + indicative (`para que llega`)  
   **Why it happens:** mood not switched.  
   **Correct Spanish:** `para que llegue`.

4. **Mistake:** present subjunctive after past main clause where "would" is intended  
   **Why it happens:** no tense backshifting.  
   **Correct Spanish:** use imperfect subjunctive (`para que supiera`).

5. **Mistake:** dropping `que` (`para lleguen`)  
   **Why it happens:** hybrid structure.  
   **Correct Spanish:** `para que lleguen`.

6. **Mistake:** wrong person in subordinate verb  
   **Why it happens:** not tracking new subject.  
   **Correct Spanish:** match the second clause subject precisely.

7. **Mistake:** literal word order in purpose clauses  
   **Why it happens:** translating chunk-by-chunk.  
   **Correct Spanish:** keep natural Spanish clause order.

8. **Mistake:** missing reflexive pronouns in infinitives (`para ir` vs `para irme`)  
   **Why it happens:** infinitive form not fully built.  
   **Correct Spanish:** include required pronoun.

9. **Mistake:** using future tense after `para que`  
   **Why it happens:** event is future in meaning.  
   **Correct Spanish:** use subjunctive, not future.

10. **Mistake:** avoiding this structure altogether  
    **Why it happens:** fear of subjunctive.  
    **Correct Spanish:** apply simple rule: subject same or different.
