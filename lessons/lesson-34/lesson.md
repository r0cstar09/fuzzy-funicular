# Spanish Daily Lesson 34: Que vs Cual Without Guesswork

## 1) cognitive_shift

**English trap**  
Trying to map English what/which directly word-for-word.

**Spanish logic**  
Spanish chooses between `que`, `cual`, and `cuales` by pattern function:
- definition vs specific data
- open question vs selection
- with/without `ser`
- choosing from an explicit group

**target pattern / formula**  
- `que + verbo` for general what questions  
- `cual(es) + verbo` for selecting options  
- `cual(es) de + grupo` for choosing from a defined set  
- `que + es/son` for definitions  
- `cual + es/son` for specific information (name, number, address)

**5 natural examples**  
1. Que necesitas ahora?  
2. Cual prefieres?  
3. Cuales de estos libros quieres?  
4. Que es la inflacion?  
5. Cual es tu numero de telefono?

## 3) pattern_mutation

Transform each base sentence as instructed.

1. Base: Que quieres? -> change verb to `necesitar`.  
2. Base: Cual prefieres? -> change to plural choices.  
3. Base: Cuales de estos libros recomiendas? -> change noun to `opciones`.  
4. Base: Que es una arepa? -> change definition target to `un contrato`.  
5. Base: Cual es tu numero de telefono? -> change requested info to `direccion`.  
6. Base: Que pelicula quieres ver? -> make it plural movie options in group form.  
7. Base: Cual de ustedes quiere ir primero? -> change to plural answer expectation.  
8. Base: Cuales son tus deportes favoritos? -> change noun to `colores`.  
9. Base: Que hiciste ayer? -> change time to `esta manana`.  
10. Base: Que dia es hoy? -> change noun to `hora`.  
11. Base: Que comes para el almuerzo? -> change meal to `la cena`.  
12. Base: Cual es tu correo electronico? -> change data field to `nombre completo`.  
13. Base: Que es ese ruido? -> change demonstrative to plural `esos ruidos`.  
14. Base: Cual es la manera mas facil de llegar alli? -> change destination to `aqui`.  
15. Base: Cual prefieres? -> change to explicit two-option contrast (`te o cafe`).

## 7) common_errors

1. **Mistake:** `Que es tu nombre?`  
   **Why it happens:** Treating identity data like definitions.  
   **Correct Spanish:** `Cual es tu nombre?`

2. **Mistake:** `Cual paso?`  
   **Why it happens:** Using `cual` in open “what happened” question.  
   **Correct Spanish:** `Que paso?`

3. **Mistake:** `Que de estas opciones prefieres?`  
   **Why it happens:** Missing selection structure with defined set.  
   **Correct Spanish:** `Cual de estas opciones prefieres?`

4. **Mistake:** always using `cual` before nouns  
   **Why it happens:** overgeneralizing English “which + noun.”  
   **Correct Spanish:** default safe pattern is often `que + noun + verb`.

5. **Mistake:** `Que es tu telefono?`  
   **Why it happens:** confusing specific data with conceptual definition.  
   **Correct Spanish:** `Cual es tu numero de telefono?`

6. **Mistake:** `Cuales es...`  
   **Why it happens:** number mismatch between interrogative and verb.  
   **Correct Spanish:** `Cual es` singular, `Cuales son` plural.

7. **Mistake:** `Que son tus deportes favoritos?`  
   **Why it happens:** using definition frame instead of specific selection info.  
   **Correct Spanish:** `Cuales son tus deportes favoritos?`

8. **Mistake:** avoiding `cual` for option selection  
   **Why it happens:** fear of ambiguity.  
   **Correct Spanish:** use `cual` when choosing among options.

9. **Mistake:** dropping accents in question words  
   **Why it happens:** orthography oversight.  
   **Correct Spanish:** `que/cual/cuales` must carry accent marks in direct questions.

10. **Mistake:** trying to memorize translation pairs only  
    **Why it happens:** no structural pattern approach.  
    **Correct Spanish:** choose by pattern role: definition, data, selection, or open query.
