# Spanish Daily Lesson 28: Color Agreement Without Translation Traps

## 1) cognitive_shift

**English trap**  
Putting color before the noun and keeping one fixed form in all contexts.

**Spanish logic**  
In Spanish, colors usually come after the noun and often agree in gender/number.  
Some colors are invariable (`naranja`, `cafe`, `violeta`, `purpura`), and the structure `color + color` avoids agreement changes.  
Use `ser` for inherent color, `estar` for temporary states/context.

**target pattern / formula**  
- `noun + variable color` -> `la camisa roja / los zapatos negros`  
- type-2 colors mostly number-only -> `azul/azules`, `verde/verdes`, `gris/grises`  
- invariable colors -> `naranja`, `cafe`, `violeta`, `purpura`  
- shade pattern -> `verde claro`, `azul oscuro`  
- safe bypass -> `noun + color + X` (`mochila color rosa`)

**5 natural examples**  
1. La pared blanca necesita pintura.  
2. Los pantalones verdes combinan bien.  
3. La mochila naranja esta en la oficina.  
4. Quiero una camisa azul oscuro.  
5. Compramos un sofa color cafe.

## 7) common_errors

1. **Mistake:** `roja casa`  
   **Why it happens:** English adjective order transfer.  
   **Correct Spanish:** `casa roja`

2. **Mistake:** `los perros negro`  
   **Why it happens:** Missing plural agreement with variable colors.  
   **Correct Spanish:** `los perros negros`

3. **Mistake:** forcing gender change on `azul/verde/gris`  
   **Why it happens:** Overgeneralizing adjective agreement.  
   **Correct Spanish:** usually number-only: `azul/azules`, `verde/verdes`, `gris/grises`

4. **Mistake:** `naranjas` / `cafes` / `purpuras` in this lesson's invariable set  
   **Why it happens:** Applying regular adjective rules to invariable colors.  
   **Correct Spanish:** `naranja`, `cafe`, `purpura`, `violeta`

5. **Mistake:** `la camisa es rojo`  
   **Why it happens:** Not matching variable color to feminine noun.  
   **Correct Spanish:** `la camisa es roja`

6. **Mistake:** `la planta es verde hoy` for temporary condition context  
   **Why it happens:** Using `ser` where temporary state is intended.  
   **Correct Spanish:** `la planta esta verde hoy`

7. **Mistake:** avoiding agreement uncertainty with broken phrase  
   **Why it happens:** Fear of adjective endings.  
   **Correct Spanish:** use safe pattern `color + X` (e.g., `mochila color rosa`)

8. **Mistake:** using `castano` for all brown objects  
   **Why it happens:** Not distinguishing lexical preferences by context.  
   **Correct Spanish:** `castano` mainly for hair/eyes.

9. **Mistake:** using `pardo` for everyday objects  
   **Why it happens:** Overextending less common lexical item.  
   **Correct Spanish:** `pardo` appears in set contexts like `oso pardo`.

10. **Mistake:** placing `claro/oscuro` before the color  
    **Why it happens:** Translating "light green" order literally.  
    **Correct Spanish:** `verde claro`, `azul oscuro`
